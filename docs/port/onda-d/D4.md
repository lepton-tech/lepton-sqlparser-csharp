## Regra aplicada

Decisão do integrador de 2026-10-14, agora escrita na `convencoes.md` §12:

- Em código **portado**, o XML doc (`<summary>`, `<remarks>`, `<param>`, `<typeparam>`, `<returns>`) tem só o texto do doc Rust, em inglês, verbatim.
- Toda nota do port vai para `//` em pt-BR, entre o bloco `///` e a declaração (ou no corpo). Exemplos de nota: "Rust: ...", "Enum ... → records (caso 37)", referências a `convencoes.md`/`nomes.md`/DIV-NNN, motivo de renomeação.
- Se um `<remarks>` mistura texto Rust e nota, só a nota sai.
- A nota de um `<param>` vira `// Nome: ...`, para não perder a ligação com o parâmetro.
- **Exceções:**
  - (a) código que não é port;
  - (b) membro que só existe no C# e não tem doc no Rust, que pode ter `///` descritivo, em inglês se for público.

Um `//` entre o `///` e a declaração não desliga o XML doc: o build não dá CS1587, como no precedente da D2 (`OneOrManyWithParens`). O Core suprime CS1591, então tirar um `<summary>` inteiro não gera aviso.

## Como foi feito

1. **Levantamento.** Script heurístico, fora do repositório, sobre os blocos `///` de `src/SqlParser.Core`, exceto `Support/` e `Generated/`. Procura acentos, palavras do português, "Rust:", "convencoes", "nomes.md", "caso N" e "→". Achou 433 blocos em 193 arquivos.
2. **Passe semiautomático** (script PowerShell, também fora do repositório), só para as formas regulares:
   - `<remarks>` inteiro em pt-BR, de uma linha ou de várias sem `<para>`/`<code>`/`<list>`, vira `//`;
   - `<summary>Rust: ...</summary>` vira `//`. São membros que traduzem `impl From`, `impl Display`, `#[derive(...)]`, campos `.0` etc., sem doc no Rust;
   - `<param name="X">Rust: campo ...</param>` vira `// X: Rust: campo ...`;
   - um `<para>` em pt-BR dentro de `<remarks>`, `<summary>` ou `<param>` vira `//`, e o resto do elemento fica.

   O texto é convertido: `<c>x</c>` vira `` `x` ``, `<see cref="X"/>` vira `X` e as entidades XML viram caracteres. A ordem das notas é mantida. O passe tocou 390 blocos em 185 arquivos. O diff foi revisado bloco a bloco.
3. **Casos mistos, à mão** (cerca de 45 blocos): texto Rust e nota na mesma linha, membros só do C# com descrição em pt-BR e `<exception>`. A lista está abaixo.
4. **Geradores** (próxima seção), seguidos de nova geração e conferência.
5. **Fins de linha preservados.** Quatro arquivos têm cabeçalho CRLF e corpo LF (`CopyIntoSnowflakeKind.cs`, `DropFunctionOption.cs`, `OnCommit.cs`, `Statement.From.cs`) e continuam assim.
