## Decisões/nomes

Não há nome novo para `nomes.md`. Decisões de tradução dos testes (as mesmas de `SpansTests`/`AstModTests` quando já existiam):

1. **Funções-atalho do arquivo:** `mysql()` e `mysql_and_generic()` viram `private static TestedDialects Mysql()` e `MysqlAndGeneric()`, copiadas nesta classe (cada fatia é uma classe própria, não `partial`).
2. **`#[cfg(not(feature = "bigdecimal"))]`** (`parse_select_with_concatenation_of_exp_number_and_numeric_prefix_column`): o Core não tem a feature `bigdecimal` (números são `string`), então o teste roda sempre. O comentário do Rust foi mantido.
3. **`match stmt { Variante(x) => .., _ => unreachable!() }`** → `Assert.IsType<Statement.Variante>(stmt)`. Padrões com guarda ou com campos fixos (`or: None, limit: None .. if optimizer_hints.is_empty()`, `Revoke { grant_option_for: false, .. }`, `Some(CreateViewParams { .. })`) → `switch`/`is` com o mesmo padrão de propriedades. `unreachable!()` → `throw new InvalidOperationException("internal error: entered unreachable code")` (constante `Unreachable`). `panic!("Unexpected statement {stmt}")` → `Assert.Fail($"Unexpected statement {stmt}")`.
4. **`assert_matches!(x, P)`** → `Assert.True(x is P)`, com padrões de propriedade estendidos (`DropForeignKey { Name.Value: "foo_ibfk_1" }`); quando o padrão é só a variante (`ParserError::ParserError(_)`), `Assert.IsType<ParserError.ParserErrorValue>(err)`.
5. **Ordem no `Assert.Equal`:** a do Rust, exceto quando um lado é literal (vai na posição "expected", regra xUnit2000). `assert_eq!(x.len(), n)` → `Assert.Equal(n, x.Count)`, com o xUnit2013 suprimido no arquivo (`#pragma`), como em `SpansTests`. `assert_eq!(None, x)` → `Assert.Null(x)`. Comparações entre a base e uma variante usam `Assert.Equal<AlterTableOperation>(..)` quando a inferência de tipo pegaria a variante.
6. **`if let [Grantee { .. }] = grantees.as_slice()`** → `grantees.Count == 1 && grantees[0] is { .. }`. Não usei padrão de lista (`is [..]`) em `Sequence<T>` para não depender de `System.Index` no net48.
7. **`.into()`**: `&str` → `Ident` vira `Ident.From("..")` (e `Ident::new` vira `new Ident(..)`); `Value` → `ValueWithSpan` vira `ValueWithSpan.From(..)` (caso 7). `Ident { value, quote_style: None, span: Span::empty() }` → `new Ident("..", null, Span.Empty())`.
8. **`.unwrap()` em `Option`:** `select.select_modifiers.unwrap().x` → `select.SelectModifiers!.X` (um `null` derruba o teste com `NullReferenceException`, como o `panic` do Rust); `query.body.as_select().unwrap()` → `Assert.NotNull(select)`. `assert!(table.is_some())` → `Assert.NotNull`.
9. **Closures locais** (`let div = |left, right| ..; let num = |n| ..;` em `parse_div_precedence`) → `Func<Expr, Expr, Expr> div` e `Func<string, Expr> num`, com os nomes do Rust.
10. **Sombreamento** (`let stmt = ..parse_sql_statements(..).unwrap()` em `parse_set_names`, de outro tipo) → variável `stmts` (caso 72); sombreamentos do mesmo tipo (`let sql1`, `let operation`, `let select`) viram reatribuição.
11. **`run_parser_method(sql, |p| p.parse_expr()).expect_err(..)`** e **`parse_sql_statements(..).expect_err(..)`/`.is_err()`** → `Assert.Throws<ParserException>(..)`; `.is_ok()` → a chamada direta (se lançar, o teste falha). `#[should_panic = "msg"]` → `Assert.ThrowsAny<Exception>` + `Assert.Contains("msg", ex.Message)` (a mensagem de `VerifiedStmt` inclui o erro do parser).
12. **Strings Rust:** `r#".."#` com aspas duplas → raw string literal C# (`"""..."""`); `r#".."#` só com `\` → `@".."`; `r#".."#` de várias linhas (`parse_looks_like_single_line_comment`) → concatenação com `\n` explícito e a mesma indentação; continuação `\` no fim da linha (`test_optimizer_hints`) → concatenação dos pedaços sem a indentação removida (B1, decisão 13).
13. **`call("CURRENT_TIMESTAMP", [])`** → `TestUtils.Call("CURRENT_TIMESTAMP", System.Array.Empty<Expr>())`: `System.` qualificado porque `Array` sozinho fica ambíguo com `Ast.Array` (CS0104, caso 49).
14. **`names.iter().map(ToString::to_string).collect::<Vec<_>>()`** → `drop.Names.Select(n => n.ToString()).ToList()` comparado com `new[] { ".." }`.
15. **`format!("..{ty}..")`** → interpolação `$"..{ty}.."`; a variável `using` (palavra reservada em C#) vira `@using` (caso 56).
