## Decisões/nomes

Nenhum nome novo para `nomes.md` e nenhuma decisão nova para `convencoes.md` §13: o arquivo só usa a API de teste já portada (`TestedDialects`, `TestUtils`) e os nomes já registrados (`Subscript.Index(IndexValue)`, `Expr.MakeValue`, `ParserError.ParserErrorValue`, `Statement.Declare(Stmts)`, `Ast.X` qualificado etc.). Escolhas de tradução, todas seguindo precedentes (`AstModTests`, `SpansTests`, `onda-b/B7.md`):

1. **Funções-atalho do arquivo.** `fn bigquery()` e `fn bigquery_and_generic()` → `private static TestedDialects Bigquery()` / `BigqueryAndGeneric()` (nome mecânico), **na mesma posição do Rust** (entre `parse_bigquery_create_external_table_with_connection` e `parse_map_access_expr`), para manter o diff com o upstream trivial.
2. **Funções aninhadas dentro de um teste** (`fn test_table_ident` e `fn test_table_ident_err`, em `parse_table_identifiers`) → funções locais `static` com nome mecânico (`TestTableIdent`, `TestTableIdentErr`), no mesmo lugar. Os `///` delas viraram `//`, porque função local não aceita comentário XML.
3. **Helpers de `test_utils`** chamados com o nome da classe (`TestUtils.ExprFromProjection`, `TestUtils.Number`, `TestUtils.TableFromName`, `TestUtils.TableAlias`, `TestUtils.Only`, `TestUtils.AllDialectsExcept`), sem `using static`, como na tabela da skill `port-rust-tests`. Assim também se evita confundir o método `TestUtils.Join` com o tipo `Ast.Join`.
4. **`match` / `let .. else` com `unreachable!()` ou `panic!(..)`** → `switch` com padrão de propriedade (`case Statement.CreateView { Value: var createView }:`; `case Statement.Delete { Value.From: FromTable.WithoutKeyword { Value: var from } }:`) ou `if (x is not P) throw ..`, com `throw new InvalidOperationException("unreachable")` / `("invalid query")` (convencoes.md §8). O `if let` interno sem `else` de `parse_byte_literal`/`parse_raw_literal` foi mantido sem `else`, como no Rust.
5. **Asserções.** `assert_eq!` na ordem do Rust, salvo literal, que vai na posição "expected" (regra xUnit2000; só ocorre em `test_export_data`, com `err.to_string()`). `assert_eq!(1, v.len())` → `Assert.Equal(1, v.Count)`, com `#pragma warning disable xUnit2013` no arquivo (precedente de `SpansTests`). `assert!(!x)` → `Assert.False(x)`; `assert!(x.is_none())`/`is_some()` → `Assert.True(x is null)` / `Assert.True(x is not null)`. Onde a inferência de tipo do xUnit ficaria ambígua (expected é uma variante e actual é a base), o tipo genérico é explícito: `Assert.Equal<TableFactor>`, `Assert.Equal<SqlOption>`, `Assert.Equal<Statement>`, `Assert.Equal<ValueTableMode?>`. A comparação de tupla de `parse_create_table_with_options` (`(partition_by, cluster_by, table_options)`) virou uma tupla C# com o tipo explícito `(Expr?, WrappedCollection<Sequence<Expr>>?, CreateTableOptions)`.
6. **Erros esperados.** `parse_sql_statements(sql).unwrap_err()` → `Assert.Throws<ParserException>(() => ..).Error`, comparado com `new ParserError.ParserErrorValue(..)`; `assert!(..is_err())` → `Assert.Throws<ParserException>(..)`; `err.to_string()` → `ex.Error.ToString()` (o `Display` com o prefixo `sql parser error: `).
7. **Strings.** `r#"..."#` → raw string literal `"""..."""` quando o conteúdo não começa nem termina com aspas e não tem três aspas seguidas; caso contrário, string comum com `\"` e `\\` (por exemplo `r#""""triple-double\"escaped""", "#` → `"\"\"\"triple-double\\\"escaped\"\"\", "`). `r"..."` com barras invertidas e sem aspas → string verbatim `@"..."` (`@"SELECT CAST(B'\x48\x65\x6c\x6c\x6f' ...)"`, `@"f\(abc,(.*),def\)"`). `concat!(..)` → `string.Concat(..)`; `format!("..{x}..")` → interpolação `$"..{x}.."`. Conferido depois da escrita que as barras continuam no arquivo (o `Find-SuspiciousChars` não acusa nada).
8. **Construção da AST esperada.** Argumentos nomeados quando o record tem mais de 3 campos ou quando a ordem C# difere da ordem dos campos no literal Rust (`Values(ValueKeyword:, ExplicitRow:, Rows:)`, `Expr.Trim(Expr:, TrimWhere:, TrimWhat:, TrimCharacters:)`). `Sequence.Of<T>(..)` com tipo explícito sempre que os elementos são de uma variante mas o campo pede a base (`Sequence.Of<Expr>(new Expr.Identifier(..))`). `Default::default()` em campos `Option`/`Vec` → `null` / `Sequence<T>.Empty`. `"x".into()` para `Ident` → `Ident.From("x")`; `Ident::new("x").into()` para `ObjectName` → `ObjectName.From(new Ident("x"))`. `stmts.swap_remove(0)` (só lê o primeiro) → `stmts[0]`. `d.is::<BigQueryDialect>() || d.is::<GenericDialect>()` → `d is BigQueryDialect || d is GenericDialect` (caso 8).
