## Decisões/nomes

Nenhum nome novo foi criado no Core. Escolhas de tradução feitas só neste arquivo de teste (seguem precedentes de `AstModTests`/`SpansTests`, da skill `port-rust-tests` e da C2):

1. **Classe própria, não `partial`** (`SqlParserCommonTests3`), por instrução da coordenação. As funções-atalho do arquivo Rust que estão no trecho (`parse_sql_statements`, `one_statement_parses_to`, `non_left_associative_dialects`, `verified_stmt`, `verified_query`, `verified_only_select`, `verified_expr`, linhas 10994–11020, e `make_where_clause`, linha 12356) viraram métodos `private static` na mesma posição relativa do Rust (`ParseSqlStatements`, ..., `MakeWhereClause`). `NonLeftAssociativeDialects` não é usado no trecho, mas foi portado por estar nele. Nenhum outro auxiliar de fora do trecho é usado; os de `test_utils` são chamados como `TestUtils.X`.
2. **Ordem do `assert_eq!`.** Mantida a do Rust, exceto quando um lado é literal (vai para `expected`, regra xUnit2000). `assert_eq!(None, x)`/`assert!(x.is_none())` → `Assert.Null(x)`; `assert_eq!(x, false)` → `Assert.False(x)`; `assert!(v.is_empty())` → `Assert.True(v.IsEmpty)`; `assert_eq!(v.len(), n)` → `Assert.Equal(n, v.Count)` com `#pragma warning disable xUnit2013` no arquivo. Quando o esperado é uma variante e o obtido é a base, `Assert.Equal<T>` com o tipo explícito (`Assert.Equal<ObjectType>(..)`, `Assert.Equal<Statement>(..)`).
3. **`match stmt { Statement::X { .. } => .., _ => unreachable!() }`** → `Assert.IsType<Statement.X>(stmt)` quando o padrão só seleciona a variante; quando o padrão também filtra campos (`name: Some(name)`, `nulls_distinct: None`, `grant_option_for: false`, `objects: Some(GrantObjects::Tables(..))`, tuplas `match (a, b)`) → `switch` com padrões de propriedade/posicionais e `default: throw new InvalidOperationException("unreachable")` (`convencoes.md` §8). `panic!(msg)` → `throw new InvalidOperationException(msg)`. `let P = x else { unreachable!() };` → `if (x is not P) throw ..`. `if let P = x { .. }` sem `else` continua sem `else` (passa em silêncio, como no Rust).
4. **`assert_matches!(x, P if matches!(..))` e `assert!(matches!(x, P))`** → `Assert.True(x is P)` com padrões aninhados (`Expr.UnaryOp { Op: UnaryOperator.Not, Expr: Expr.IsJson }`, `TableFactor.Pivot { Table: TableFactor.Table { Alias: null } }`).
5. **Erros.** `.unwrap_err()` → `Assert.Throws<ParserException>(..).Error` comparado com `new ParserError.ParserErrorValue(..)`/`new ParserError.RecursionLimitExceeded()`; `assert!(r.is_err(), ..)` → `Assert.Throws<ParserException>(..)`; `assert!(r.is_ok())`/`.unwrap()`/`Ok(_) => {}` → a chamada não lançar; `Parser::new(&d).try_with_sql(&sql).expect(..)` → `new Parser(d).TryWithSql(sql)` (o `.expect` fica em comentário).
6. **`#[should_panic(expected = "..")]`** (`ensure_multiple_dialects_are_tested`) → `Assert.ThrowsAny<Exception>(..)` + `Assert.Contains("..", ex.Message)`; o atributo Rust fica em comentário acima do `[Fact]`.
7. **`fn` aninhada dentro do teste** (`test_with`, `chk`, `test_time_function`, `assert_mysql_query_value`, `expected_function`) → função local `static` com o nome mecânico (`TestWith`, `Chk`, ...).
8. **Mutação de valores imutáveis.** `ast.locks.pop()`/`ast.locks.remove(0)` sobre `Sequence<LockClause>` → `Locks.ToList()` + leitura do elemento + `RemoveAt` (mesma ordem de consumo); `revoke.grant_option_for = false` e `ast_without_parens.args = ..` → expressão `with`. O identificador `lock` virou `@lock` e `params` virou `@params` (`convencoes.md` §13, caso 56).
9. **Strings.** `\` no fim da linha → concatenação sem a quebra e sem a indentação seguinte; `concat!(..)` → `string.Concat(..)`; `format!` → interpolação; `"x".repeat(n)` → `new string(c, n)` ou `string.Concat(Enumerable.Repeat(..))`; `r"..."`/`r#"..."#` com barras → string verbatim `@".."` (aspas dobradas); o `r#"..."#` de várias linhas de `parse_start_transaction` → `\n` explícito (o `.editorconfig` grava `.cs` com CRLF). Escapes do valor esperado em `parse_escaped_string_with_unescape`: `\u{8}` → `\b`, `\u{7}` → `\a`, `\u{1a}` → `\x001A` (quatro dígitos, para o `\x` não engolir caracteres seguintes e sem usar a forma com barra e `u`, que as ferramentas de edição convertem).
10. **`Box<Query>` com `.clone().into()`** → a própria `Query` (records são imutáveis). `Vec::from(ALL_KEYWORDS)` + `sort_unstable()` → `new List<string>(Keywords.AllKeywords)` + `Sort(string.CompareOrdinal)` (ordem de bytes, igual à do Rust para as keywords ASCII).
11. **Nomes não mecânicos do Core usados aqui** (já existentes, só registro de uso): `Statement::CreateDatabase.clone` → `CloneValue`; `CreateIndex.r#async` → `Async`; `Action` → `Ast.Action` (CS0104 com `System.Action`, caso 49); `Rollback.savepoint` e os `schemas` de `GrantObjects::All*InSchema` usam as propriedades declaradas com `new` (caso 58); `CastKind` e `SelectFlavor` são `enum` C#; `Expr::value(..)` → `Expr.MakeValue(..)`.
