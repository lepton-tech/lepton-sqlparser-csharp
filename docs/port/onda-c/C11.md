## Decisões/nomes

Nenhum nome novo de AST. As decisões abaixo são só de tradução de teste e seguem os precedentes de `SqlParserSnowflakeTests2` (C12) e de `AstModTests`/`SpansTests`:

1. **Funções-atalho do arquivo** copiadas como `private static` (nomes mecânicos), no topo da classe: `Snowflake()`, `SnowflakeWithRecursionLimit(int)`, `SnowflakeWithoutUnescape()` e `SnowflakeAndGeneric()`. No Rust ficam nas linhas 1480–1500, no meio da fatia; ali ficou só um comentário apontando para o topo. A classe é própria (não `partial`). `SnowflakeWithRecursionLimit` não é usada nesta fatia; foi mantida para a classe espelhar o conjunto de atalhos do arquivo, como na C12.
2. **Analisadores do xUnit sob `TreatWarningsAsErrors`:**
   - `assert_eq!` na ordem do Rust, salvo quando um lado é literal ou constante de `enum` C# (`CopyIntoSnowflakeKind.Table`): o literal vai na posição "expected" (xUnit2000);
   - `assert!(v.contains(&x))` → `Assert.Contains(x, v)` (xUnit2017);
   - `assert_eq!(Some(true), x)` / `assert_eq!(Some(false), x)` com `x: Option<bool>` → `Assert.True(x)` / `Assert.False(x)`, sobrecargas de `bool?` que falham com `null`, como a comparação do Rust (xUnit2004);
   - `assert_eq!(Some(5), x)` com `x: Option<u64>` → `Assert.Equal<ulong?>(5, x)`;
   - `assert_eq!(1, v.len())` → `Assert.Equal(1, v.Count)`, com `#pragma warning disable xUnit2013` no arquivo;
   - `assert!(x.is_none())` / `is_some()` → `Assert.Null` / `Assert.NotNull`; `assert_eq!(None, x)` → `Assert.Null(x)` (xUnit2003).
3. **`Option` e erros:**
   - `x.unwrap()` / `x.expect(msg)` → `x ?? throw new InvalidOperationException(..)` (mensagem do `unwrap` do Rust numa constante `UnwrapNone`);
   - `x.map(|p| p.to_string())` comparado a `Some("..")` → `Assert.Equal("..", x?.ToString())`;
   - `parse_sql_statements(..).unwrap().pop().unwrap()` → `ParseSqlStatements(..).Last ?? throw ..` (o vetor não é usado depois);
   - `assert_eq!(parse_sql_statements(..), Err(ParserError::ParserError(..)))` → `Assert.Equal<ParserError>(Assert.Throws<ParserException>(..).Error, new ParserError.ParserErrorValue(..))` (ordem do Rust);
   - `.unwrap_err().to_string()` → `Assert.Throws<ParserException>(..).Error.ToString()`; `.is_err()` → `Assert.Throws<ParserException>(..)`; `.is_ok()` e `.unwrap()` sem uso do valor → chamada direta (`_ = ..`), que falha o teste se lançar.
4. **`match`/desestruturação:**
   - `match stmt { Statement::CreateTable(CreateTable { campos, .. }) => .., _ => unreachable!() }` → `switch` com padrão de propriedades (`case Statement.CreateTable { Value: { Name: var name, .. } }:`) e `default: throw new InvalidOperationException("unreachable")`; com muitos campos, `case .. { Value: var createTable }:` + locais com os nomes Rust;
   - `with_no_schema_binding: late_binding` → local `lateBinding`; `panic!(msg)` → `Assert.Fail(msg)`;
   - `SqlOption::Comment(CommentDef::WithEq(c)) | SqlOption::Comment(CommentDef::WithoutEq(c)) => c` → dois braços de `switch` expression com o mesmo resultado;
   - `let Declare { .. } = stmts.swap_remove(0);` → `var declare = stmts[0];` + locais com os nomes Rust (com um único elemento, `swap_remove(0)` devolve o primeiro; o vetor não é usado depois);
   - `for_query.as_ref().map(|q| match q.body { SetExpr::Select(q) => .. })` → operador condicional + `switch` expression + `Select(..).ToList()`, comparado com `List<string>?`.
5. **Nomes de variáveis que o C# não aceita:**
   - campo/variável `with` (laços de `test_snowflake_create_table_with_columns_*`) → `@with` (§13, caso 56; `with` é palavra contextual);
   - `volatile` (padrão de `Statement::CreateFileFormat`) → `@volatile`;
   - `let sql = ..` depois do laço `for (sql, ..)` em `parse_snowflake_declare_result_set` → `sql2`: o C# não permite repetir o nome de uma variável de um escopo filho no escopo pai (CS0136).
6. **Literais:**
   - `concat!(..)` e a continuação `\` do Rust (`test_snowflake_create_iceberg_table_all_options`, que também descarta a indentação da linha seguinte) → concatenação dos pedaços com `+`;
   - `r#"..."#` de uma linha → string comum com `\"`;
   - `r#"..\\.."#` (`ESCAPE='\\'`) → string verbatim `@"..\\.."` (duas barras, como no Rust).
7. **Valores e AST:**
   - `"lit".into()` (para `Ident`) → `Ident.From("lit")`; `Ident::new("x")` → `new Ident("x")`;
   - `"lit".into()` / `"lit".to_string()` (para `String`) → o próprio literal;
   - `Value::X(..).with_empty_span()` → `new Value.X(..).WithEmptySpan()`; `Value::X(..).into()` (para `ValueWithSpan`) → `ValueWithSpan.From(..)`;
   - `Value::Number("1".parse().unwrap(), false)` → `new Value.Number("1", false)` (sem a feature `bigdecimal`, como `TestUtils.Number`);
   - `Expr::..(..).into()` (para `Box<Expr>` em `DeclareAssignment`) → a própria `Expr`;
   - `Tag::new(key, value)` → `new Tag(key, value)` (o construtor posicional do record);
   - `..Default::default()` em `WildcardAdditionalOptions` → `WildcardAdditionalOptions.Default() with { OptExclude = .. }` (caso 42);
   - `Some(vec![..])` comparado com `Option<Vec<T>>` → cast `(Sequence<T>?)Sequence.Of(..)` (caso 64); `Some(WrappedCollection::Parentheses(..))` → `Assert.Equal<WrappedCollection<Sequence<Expr>>?>(..)`;
   - `Whitespace::SingleLineComment { prefix, comment }` → argumentos nomeados na ordem do teste Rust (`Prefix:`, `Comment:`); o record C# declara `Comment` antes de `Prefix`, como o enum do Rust, e sem os nomes os valores trocariam de lugar.
