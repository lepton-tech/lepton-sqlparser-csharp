## Decisões/nomes

Nenhum nome novo foi criado no Core. Escolhas de tradução feitas só neste arquivo de teste (todas seguem precedentes de `AstModTests`/`SpansTests` ou da skill `port-rust-tests`):

1. **Classe própria, não `partial`.** Cada fatia de `sqlparser_common.rs` é uma classe independente (`SqlParserCommonTests2`), por instrução da coordenação. As funções-atalho do arquivo Rust (`parse_sql_statements`, `one_statement_parses_to`, `verified_stmt`, `verified_query`, `verified_only_select`, `verified_expr`, linhas 10994–11020) e a macro `nest!` (`tests/test_utils/mod.rs`) foram copiadas como métodos `private static` (`ParseSqlStatements`, ..., `Nest(TableFactor @base, params TableFactor[] joins)`). `run_explain_analyze` (função do arquivo dentro do trecho) virou `RunExplainAnalyze`, na posição do Rust.
2. **Ordem do `assert_eq!`.** Mantida a do Rust, exceto quando um lado é literal (vai para `expected`, regra xUnit2000). `assert_eq!(x, None)` → `Assert.Null(x)`; `assert_eq!(false, x)` → `Assert.False(x)`.
3. **`unreachable!()`** → `throw new InvalidOperationException(Unreachable)`, com a mensagem do Rust (`internal error: entered unreachable code`), conforme `convencoes.md` §8. **`panic!(msg)`** → `Assert.Fail(msg)` (como em `SpansTests`). `match` exaustivo sobre `Option<DropBehavior>` → `switch` com `default: throw`.
4. **`.unwrap_err()` / `.expect_err(..)`** → `Assert.Throws<ParserException>(..)`; a comparação usa `ex.Error` (`ParserError.ParserErrorValue`). `.unwrap_err().to_string().contains(..)` → `Assert.Contains(.., ex.Error.ToString())`. `err.to_string()` → `ex.Error.ToString()` (com o prefixo `sql parser error: `, como no Rust).
5. **`.unwrap()`** de um `Option` cujo valor é só comparado → comparação direta com o anulável (falha igual); quando é desreferenciado (`on_cluster.unwrap().to_string()`, `sel.with.unwrap()`, `.first().unwrap()`) → operador `!` (o `NullReferenceException` faz o papel do `panic`).
6. **Asserções booleanas sobre strings e coleções** (analisadores do xUnit tratados como erro): `assert!(s.ends_with(x))` → `Assert.EndsWith(x, s, StringComparison.Ordinal)` (xUnit2009; `Ordinal` porque o padrão do xUnit é sensível à cultura); `assert!(v.iter().any(|c| matches!(..)))` → `Assert.Contains(v, c => c is ..)` (xUnit2012); `assert!(matches!(x, P))` → `Assert.True(x is P)` com padrões de propriedade estendidos (`Value.Over: ...`).
7. **`assert_eq!(a, b, "{message}")`** (em `parse_create_table_column_constraint_characteristics`): o xUnit não aceita mensagem em `Assert.Equal`; o `Assert.Equal` fica num `try` e o `catch (XunitException)` chama `Assert.Fail($"{message}\n{e.Message}")`, como `TestedDialects.AssertEqualWithMessage`.
8. **`fn` aninhada e closures dentro do teste** (`test_combo`, `check_one`, `validate_explain`, `chk`, `join_with_constraint`, `test_constraint`, `natural_join`, `assert_ctes_in_select`, a closure `sql`) → funções locais `static` com o nome mecânico. Construtores de variante passados como função (`JoinOperator::Inner`) → lambda `c => new JoinOperator.Inner(c)`; `impl Into<String>` → `string`.
9. **Sombreamento de nomes** (`let dialects = ..` / `let sql = ..` redeclarados, proibido no C#, CS0136): nomes distintos (`snowflakeLikeDialects`, `invalidSql`, `sqlWithSchema`, `sqlWithAliases`, `sqlNamedWindow`, `dialectsWithoutNamedWindow`, `dialectsWithoutUsing`); quando o tipo é o mesmo e o escopo permite, reatribuição (`sql = ..`, `select = ..`). O identificador `with` (palavra contextual do C#) virou `@with` (`convencoes.md` §13, caso 56).
10. **Strings Rust com `\` no fim da linha** → concatenação sem a quebra e sem a indentação da linha seguinte (espaços antes da `\` preservados). Quebras de linha reais (linhas sem `\`, e o `r#"..."#` de várias linhas de `parse_json_keyword`) → `\n` explícito: o `.editorconfig` grava `.cs` com CRLF, então um raw string literal de várias linhas trocaria o conteúdo. Raw strings de uma linha (`r#"..."#`) → raw string literal C# (`"""..."""`).
11. **`format!` com argumentos posicionais** (`chk`, `parse_ctes`) → `string.Format`; com variáveis nomeadas → interpolação.
12. **Nomes não mecânicos do Core usados aqui** (já existentes, só registro de uso): `FunctionArgOperator::Equals` → `FunctionArgOperator.EqualsVariant` (CS0102, colide com `Equals` do record); `Expr::Value(v)` → `new Expr.Value(v)` com a propriedade `Inner` no padrão (`Expr.Value { Inner: .. }`); `CreateTable.clone` → `CloneValue`; `Statement::RenameTable(Vec<RenameTable>)` → `Statement.RenameTable { Value }`; `DeferrableInitial`, `CastKind` e `SelectFlavor` são `enum` C#. `FunctionArgOperator.EqualsVariant` ainda não consta de `nomes.md`: sugiro registrar quem portou `FunctionArgOperator` (não alterei `nomes.md` para não conflitar com outras fatias).
13. **`unreachable!("..., got {:#?}", select.from)`** (`parse_select_with_alias_and_column_defs`): o formato `{:#?}` (Debug do Rust) não existe no C#; a mensagem usa o `Display` de cada `TableWithJoins`. Só afeta o texto de uma falha.
