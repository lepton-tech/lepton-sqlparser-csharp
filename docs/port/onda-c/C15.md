## Decisões/nomes

Nenhum nome novo de AST. As decisões abaixo são de tradução de **testes** e seguem os precedentes de `AstModTests` e `SpansTests` (onda B, `B7.md`); convém consolidá-las em `convencoes.md` §13 quando o integrador da onda C juntar as notas.

1. **Ordem dos argumentos do `Assert.Equal`:** a do Rust, exceto quando um dos lados é literal ou constante (inclusive membro de `enum` C#, como `OnCommit.PreserveRows`): o literal vai na posição "expected" (analisador xUnit2000, que vira erro com `TreatWarningsAsErrors`).
2. **`assert_eq!(x.len(), n)`** → `Assert.Equal(n, x.Count)`, com `#pragma warning disable xUnit2013` no arquivo (como em `AstModTests`/`SpansTests`).
3. **Asserções que o analisador do xUnit proíbe na forma literal:** `assert_eq!(x, None)` → `Assert.Null(x)` (xUnit2003); `assert_eq!(x, true)` → `Assert.True(x)` (xUnit2004); `assert!(v.contains(&x))` → `Assert.Contains(x, v)` (xUnit2017). Semântica idêntica.
4. **`unreachable!()` / `unreachable!(msg)` / `panic!(msg)`** → `Assert.Fail(msg)` no `default` do `switch` (como em `SpansTests`); a mensagem de `unreachable!` é a do Rust (`internal error: entered unreachable code[: msg]`, constante privada `Unreachable`). Em função local que devolve valor (`let P = x else { panic!(..) }` em `where_operator`), `throw new InvalidOperationException(msg)`.
5. **`.unwrap()`** de `Option` → operador `!` (o teste falha com `NullReferenceException` se vier `None`); **`.expect(msg)`** → `?? throw new InvalidOperationException(msg)`; **`.expect_err(msg)`** → `Assert.Throws<ParserException>(..)` com a mensagem em comentário.
6. **`parse_sql_statements(..).unwrap_err()` comparado com `ParserError(..)`** → `Assert.Throws<ParserException>(..).Error` comparado com `new ParserError.ParserErrorValue(..)`; `.unwrap_err().to_string()` → `.Error.ToString()`.
7. **`match` com campos literais no padrão** (`Statement::Pragma { value: None, is_eq: false, .. }`, `CreateTable { without_rowid: true, .. }`, `AttachDatabase { database_file_name: Expr::Value(..), database: true }`) → padrão de propriedades C# no `case`, com o mesmo efeito: se o campo não bate, cai no `default` (o `unreachable!`).
8. **`fn` aninhada dentro de um teste** (`where_operator`, `assert_function`, os dois `check_settings`) e **closure** (`expected_column_def`) → função local `static` com o nome mecânico (`onda-b/B1.md`, item 9). Os helpers de topo do arquivo viram métodos `private static` (`Sqlite()`, `SqliteWithOptions(..)`, `SqliteAndGeneric()`, `Clickhouse()`, `ClickhouseAndGeneric()`, `ColumnDef(..)`).
9. **Helper `column_def`** → `private static ColumnDef ColumnDef(Ident name, DataType dataType)`: o nome mecânico coincide com o tipo; o C# resolve `new ColumnDef(..)` e o tipo de retorno como tipo e `ColumnDef(..)` como método, sem ambiguidade (compila sem aviso).
10. **`"x".into()` para `Ident`** → `Ident.From("x")` (`impl From<&str> for Ident`, caso 7); `Ident::new("x")` → `new Ident("x")`; `Ident::from("x")` → `Ident.From("x")`.
11. **`Expr::value(v)`** → `Expr.MakeValue(v)`; `Expr::Value(v.with_empty_span())` → `new Expr.Value(v.WithEmptySpan())`; `"1".parse().unwrap()` (número sem a feature `bigdecimal`) → `"1"`.
12. **Ternário entre variantes diferentes** (`if op == "ATTACH" { AttachPartition {..} } else { DetachPartition {..} }`) → `? .. : (AlterTableOperation)..`, para a inferência de tipo do `Assert.Equal`.
13. **`Some(expected)` comparado com `Option<Vec<T>>`** (`q.settings`) → `(Sequence<Setting>?)expected`; `Some(vec![])` × `None` em `Interpolate.Exprs` → `Sequence<InterpolateExpr>.Empty` × `null` (caso 64).
14. **`{keyword:?}`** num `format!` → `keyword.ToString()` (nome da variante, caso 46).
15. **Strings:** `r#"..."#` com aspas → string verbatim `@"..."` com aspas dobradas (inclusive `'\d+'` de `test_regexp_operator`, que no Rust é raw e não tem escape); `concat!(..)` → `+`; continuação `\` no fim da linha → pedaços concatenados sem a indentação seguinte (`onda-b/B1.md`, item 13). Em `parse_select_order_by_interpolate_not_last`, a linha de `fname` **não** termina com `\` no Rust, então a string mantém `",\n"` + 12 espaços antes de `lname`.
16. **`for (operator, expected) in [..]`** → `foreach (var (@operator, expected) in new (string, BinaryOperator)[] { .. })` (`operator` é palavra reservada, caso 56). A mensagem extra de `assert_eq!(.., "{operator}")` não tem equivalente no `Assert.Equal` genérico do xUnit e foi omitida (comentário no teste); o SQL com o operador continua visível na falha pela pilha.
17. **`projection: &Vec<SelectItem> = ..as_ref()`** → `IReadOnlyList<SelectItem> projection = ..Projection` (a `Sequence<T>` já é `IReadOnlyList<T>`).
