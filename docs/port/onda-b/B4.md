## Decisões (para convencoes.md §13)

1. **`break` do laço dentro de um `match` usado como expressão** (`let next_precedence = match op { .., None => break }` em `parse_remaining_set_exprs`; `let join_operator_type = match peek_keyword { .., _ => break }` em `parse_joins`): quando depois do laço só há `Ok(x)`, o `case` faz `return x;` direto, com comentário. Assim a variável calculada continua definitivamente atribuída nos outros braços. Nos `match` usados como instrução (`parse_string_values`, `parse_identifiers`, `parse_multipart_identifier`, `parse_optional_type_modifiers`), continua a flag `stop` de `ParseStatements` (B0).
2. **`match &mut x.campo { A { alias, .. } | B { alias, .. } | .. => { corpo que lê e altera `alias` } }` sobre records imutáveis** (o `outer_alias` de `parse_table_factor`): o corpo do braço vira uma função local `static` (`ReplaceAlias(TableAlias? alias, TableAlias outerAlias)`, que valida e devolve o novo valor), e cada `case` reconstrói a variante com `with` (`tableAndJoins = tableAndJoins with { Relation = t with { Alias = ReplaceAlias(t.Alias, outerAlias) } }`). Um `match` continua sendo um `switch`; o `match` exaustivo ganha `default: throw new InvalidOperationException(..)`.
3. **`matches!(self.peek_tokens(), [padrão, padrão])` no meio de uma cadeia de `else if`** (`parse_table_factor`, `VALUES (`): padrão de lista sobre o array devolvido por `PeekTokens(n)` (`PeekTokens(2) is [Token.Word { Value.Keyword: Keyword.VALUES }, Token.LParen]`). Extensão do caso 51: o `var t = PeekTokens(2);` antes da cadeia não serve, porque os ramos anteriores consomem tokens.
4. **`keywords::RESERVED_FOR_*` passado a um parâmetro `&[Keyword]`** (`self.parse_optional_alias(keywords::RESERVED_FOR_COLUMN_ALIAS)`): `Keywords.ReservedForColumnAlias` é `IReadOnlyList<Keyword>` e o parâmetro é `params Keyword[]` (caso 50); a chamada usa `.ToArray()`.
5. **`Option<&[Keyword]>`** (`parse_optional_alias_inner`): `Keyword[]?` (não há `params` com `Option`). Fecha a escolha que a B1 deixou aberta (`IReadOnlyList<Keyword>?` ou `Keyword[]?`); `params Keyword[]` converte direto.
6. **`TokenWithSpan` → `AttachedToken`**: `AttachedToken(tok)` → `new AttachedToken(tok)` (padrão das unidades anteriores); `tok.into()` / `tok.clone().into()` → `AttachedToken.From(tok)` (caso 7). Primeiro uso de `.into()` com tokens: `parse_query` (`with_token`), `parse_cte` (`closing_paren_token`), `parse_delete` (`delete_token`), `maybe_parse_connect_by`.
7. **`with_state`** (`let current_state = self.state; self.state = state; let res = f(self); self.state = current_state; res`): `try { return f(this); } finally { _state = currentState; }`. O Rust restaura o estado também quando `f` devolve `Err`; com exceções, isso é o `finally`.
8. **Função livre de um módulo de dialeto chamada pelo parser** (`crate::dialect::parse_snowflake_stage_name(self)`, de `dialect/snowflake.rs`, reexportada por `dialect/mod.rs`): suposta como membro `public static` do tipo principal do arquivo, `SnowflakeDialect.ParseSnowflakeStageName(Parser parser)` (extensão do caso 5: o arquivo `dialect/snowflake.rs` vira `SnowflakeDialect.cs`, e uma classe `SnowflakeModule` seria artificial). Decisão a confirmar pela B6, que porta essas funções (ver "Pendências").
9. **`Option<Option<Expr>>` com `limit != Some(None)`** (`parse_optional_limit_clause`): `Option<Expr?>` (caso 55); `limit.is_some() && limit != Some(None)` → `limit.IsSome && limit.Value is not null`; `limit.unwrap_or_default()` → `limit.IsSome ? limit.Value : null`. A tupla `(limit, limit_by)` é atribuída por desconstrução (decisão 7 da B2).
10. **Sombreamento dentro de closures**: o C# 8+ permite que locais e parâmetros de lambdas e funções locais sombreiem locais do método. As closures mantêm os nomes Rust (`query`, `closing_paren_token` em `parse_cte`; `alias` em `parse_match_recognize`; o parâmetro `explicit` do `validator` aninhado em `maybe_parse_table_alias`, que tem um local `explicit`). O caso 72 (renomear) só vale para blocos aninhados comuns, inclusive variáveis de padrão em condições de `if`/`else if` (`if let Some(idx) = .. else if let Some(idx) = ..` → `startIdx`, `connectIdx`), que vazam para o bloco que contém o `if`.
11. **Alteração de campo `String` de record** (`ident.value.push('-')`, `ident.value.push_str(..)` em `parse_unquoted_hyphenated_identifier`): `ident = ident with { Value = ident.Value + "-" }` (mesma família da decisão 3 da B3).
12. **`#[allow(clippy::...)]`**: não traduzido (comentário na posição, como o `#[must_use]` da B3).
13. **Identificadores contextuais**: `on` (palavra de consulta LINQ) → `@on` (decisão 14 da B2). `type` e `global` não são palavras-chave do C# e ficam sem `@`; `r#type` → `type` (§4).
14. **`str::split_once('+')?`** (`extract_hint_prefix_and_text`): `IndexOf('+')` (ordinal) + `Substring`, devolvendo `null` quando não há `+`. `is_ascii_alphanumeric()` → `RustChar.IsAsciiDigit(c) || RustChar.IsAsciiLowercase(c) || RustChar.IsAsciiUppercase(c)` (§10; sem novo membro em `RustChar`).
15. **Construtores de variante usados como função** (`join_operator_type = JoinOperator::Inner` etc. em `parse_joins`): `Func<JoinConstraint, JoinOperator>` atribuído com lambdas (`c => new JoinOperator.Inner(c)`), caso 27.
16. **`.into_iter().flatten().collect()` sobre `Vec<Option<T>>`** (`lateral_col_alias` em `parse_select`): `.OfType<T>().ToSequence()` (código frio, §9).
