## Decisões (para convencoes.md §13)

1. **`.is_ok()` sobre `Result`** (`if self.expect_token(&Token::LParen).is_ok()`, em `parse_optional_column_option_generated`): `bool lparenOk; try { ExpectToken(..); lparenOk = true; } catch (ParserException) { lparenOk = false; }`, sem restaurar `_index` (o `expect_token` não consome nada quando falha). Mesma família da decisão 1 da B2 (`.ok()`).
2. **`Result` guardado sem `?` e propagado depois, repetido muitas vezes** (`let optional_precision = self.parse_optional_precision();` + `self.parse_keyword(Keyword::UNSIGNED)` + `optional_precision?`, oito vezes em `parse_data_type_helper`): em vez de repetir o `try/catch` da decisão 4 da B1 em cada braço, duas funções locais no método: `ParseOptionalPrecisionResult()`, que devolve `(ulong? Value, ParserException? Error)`, e `static Unwrap(..)`, que relança o erro guardado no ponto do `?`. A ordem de consumo de tokens é a do Rust (o `UNSIGNED`/`SIGNED` é consumido antes de o erro sair).
3. **`let mut x = T::default(); x.campo = v;` sobre record imutável** (`ConstraintCharacteristics` em `parse_constraint_characteristics`): `cc = cc with { Campo = v }` (extensão da decisão 6 da B2).
4. **Tamanho de `String` em bytes e `{s:?}` de `str`** (`parse_literal_char`): `s.len() != 1` → `System.Text.Encoding.UTF8.GetByteCount(s) != 1` (o Rust conta bytes UTF-8, convencoes.md §10; um caractere não ASCII é rejeitado, como no Rust); `s.chars().next().unwrap()` → `s[0]` (com 1 byte UTF-8 o caractere é ASCII). `format!("... {s:?}")` → `TokenDebugExtensions.DebugStr(s)`, que passou de `private` a `internal` (mesmo formato `Debug` de `str` usado pela B1).
5. **Padrão `|` com ligação de variável** (`Token::SingleQuotedString(ref s) | Token::DoubleQuotedString(ref s)`, em `maybe_concat_string_literal`): no `while let`, um `switch` extrai `s` e o `default` encerra (decisão 5 da B2); no braço de `match` com guarda (`.. if after_newline => { corpo }`), o corpo aparece nas duas seções `case`, cada uma com o seu `when afterNewline`.
6. **Guardas de `match` com efeito colateral** (`Some(Keyword::FORCE) if self.parse_keywords(&[NOT, NULL]) => ..`, em `parse_copy_legacy_csv_option`): `case Keyword.FORCE when ParseKeywords(Keyword.NOT, Keyword.NULL):` na mesma ordem. O C# avalia os `when` em ordem textual e só quando o padrão casa, como o Rust; comentário no código.
7. **Closures locais**: `let ok_value = |value: Value| Ok(value.with_span(span));` (captura `span`) → função local não estática `ValueWithSpan OkValue(Value value)` (o `Ok` some, caso 45); `let parse_string_expr = |parser: &mut Parser| -> Result<Expr>` (não captura nada) → função local `static Expr ParseStringExpr(Parser parser)`, chamada com `this` (decisão 9 da B1).
8. **`System.Text` no parser**: `using System.Text;` torna `NormalizationForm` ambíguo com `Ast.NormalizationForm` (CS0104). Não importar o namespace; qualificar `System.Text.StringBuilder` / `System.Text.Encoding` (mesma ideia do caso 49).
9. **`core::mem::take(&mut content)` sobre `String`** (`parse_tab_value`): `content` é um `System.Text.StringBuilder`; `take` → `content.ToString()` seguido de `content.Clear()`.
10. **`match` sobre enum com dados que devolve tupla** (`let (function, aggregate_star, aggregate_order_by) = match kind { Function => (..), Aggregate => self.parse_alter_aggregate_signature()? }`): locais declarados antes e um `switch` com desconstrução em cada seção; `default: throw new InvalidOperationException(..)` porque o `match` é exaustivo sobre `AlterFunctionKind` (abstract record).
11. **Identificador contextual `equals`** (`let equals = self.consume_token(&Token::Eq)` em `parse_alter_table_operation`): `@equals` (decisão 14 da B2: palavra de consulta LINQ).
12. **`#[must_use]`** (`parse_index_type_display`): não traduzido (comentário na posição).
13. **`matches!(opt, Some(Keyword::FALSE))` sobre `Option<Keyword>`**: `opt is Keyword.FALSE` (padrão constante sobre `Keyword?`; `None` não casa). `!matches!(..)` → `is not`.
