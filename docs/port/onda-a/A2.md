## Decisões (para convencoes.md §13)

1. **Campo de variante-struct com o nome de OUTRA variante do mesmo enum** (ex.: `Statement::AlterView { query, .. }` convive com a variante `Statement::Query`). O record derivado herda o tipo aninhado `Statement.Query`, e o compilador não sintetiza a propriedade do parâmetro posicional (**CS8866**). Tradução: manter o nome Rust e declarar a propriedade explicitamente no corpo do record, com `new`:
   ```csharp
   public sealed record AlterView(ObjectName Name, Sequence<Ident> Columns, Ast.Query Query, Sequence<SqlOption> WithOptions) : Statement
   {
       public new Ast.Query Query { get; init; } = Query;
   }
   ```
   Construtor posicional, argumentos nomeados, `Deconstruct`, `with { Query = .. }` e igualdade continuam funcionando (verificado). Ocorrências em A2: `AlterView.Query`, `Cache.Query`, `Unload.Query`, `AlterSession.Set`, `Rollback.Savepoint`, `Deallocate.Prepare`, `Explain.Analyze`, `CreateDatabase.Comment`, `CreateStage.Comment`, `CreateFileFormat.Comment`. **Atinge outros enums** (provável em `Expr`: `InSubquery { subquery, .. }` × variante `Subquery`, entre outros). Primeiro uso: `Ast/Mod/Statement.cs`.
2. **Membro chamado `Clone` em record** (CS8859): sufixo `Value` (`CloneValue`), como no caso 41. Primeiro uso: `Statement.CreateSchema`/`CreateDatabase`.
3. **`format!`/`to_string()` usados para montar um pedaço de um `write!`** (`tables = if .. { format!(" {}", x) } else { String::new() }` em `Flush`; `as_type = [" AS ", &dt.to_string()].concat()` em `CreateSequence`): escrita condicional direta (`if (..) f.Write($" {x}");`) na mesma posição da saída. Uma lacuna `{x}` usa flags novos, como o `format!`/`to_string()`, então o texto é o mesmo; isso segue a proibição de `ToString()` dentro de `Display` (caso 30). Comentário no código aponta o trecho Rust.
4. **`writeln!(f, ";")`** → `f.Write($";\n")`: um único pedaço `";\n"`, como o `format_args_nl!` do Rust (importa para o `Indent`, que só reage a `"\n"` isolado). **`write!(f, "")`** → nada (comentário no lugar).
5. **`match (*has_as, query) { (true, Some(q)) => .., (true, None) => .., .. }`** → `switch ((cache.HasAs, cache.Query)) { case (true, { } query): .. case (true, null): .. }`: padrões de tupla C#, os 4 braços na ordem do Rust, mais o `default: throw` da §6.3 (inalcançável, mas mantém a regra).
6. **`let (open, close) = if c { (a, b) } else { (x, y) };`** → `var (open, close) = c ? (a, b) : (x, y);`.
7. **`partial` de `Statement`**: `Statement.cs` (variantes + `From` de 5026–5048) e `Statement.Display.cs` (`: IDisplay`, `Fmt`, `sealed override ToString()`). Os demais `impl From<X> for Statement` (mod.rs 12284–12632, unidade A4) devem entrar em outro arquivo `partial` (sugestão: `Statement.From.cs`), usando `Ast.X` para os tipos homônimos de variantes.
8. **Doc comments**: ` ```sql ` → `<code>`; `[texto](url)` → `<see href="url">texto</see>`; `<url>` → `<see href="url"/>`; lista numerada → `<list type="number">`; `<`/`>`/`&` escapados. Comentários `//` do Rust (`// TODO: Support ROW FORMAT`, `// processlist_id`, o bloco `// SHOW {CHARACTER SET | CHARSET}`) mantidos na mesma posição.

Avisos para outras unidades e para o integrador:

- **A4 (`impl From<X> for Statement`)**: `From<Query>` e `From<Box<Query>>` viram a mesma assinatura C# (`From(Ast.Query)`); só uma sobrecarga é possível.
- **Uso de `Statement.X` fora de `Statement`**: os tipos aninhados `Statement.AlterType`, `Statement.DropDomain`, `Statement.ShowObjects`, `Statement.Insert`, `Statement.Query` etc. têm o nome de tipos de topo, e `Statement.Directory` tem o nome de `System.IO.Directory`. Com `using static SqlParser.Core.Ast.Statement;` as referências ficam ambíguas (CS0104). O parser e os testes devem escrever `Statement.X` (ou `new Statement.Insert(..)`), sem `using static`.
- **Visitor**: `[VisitWith("visit_statement")]` está na base abstrata; `visit_relation` nos campos `CreateVirtualTable.Name`, `AlterView.Name`, `ExplainTable.TableName`, `Cache.TableName`, `UNCache.TableName`.
- Erros de build restantes nos arquivos de A2: só CS0246/CS0234 de tipos ainda não portados por outras unidades.
