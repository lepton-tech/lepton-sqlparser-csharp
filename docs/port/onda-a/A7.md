## Decisões (para convencoes.md §13)

1. **`debug_assert!(cond)` em código de produção** (`LimitClause` `Display`: `debug_assert!(limit.is_some())`). Tradução: o mesmo `throw` do caso 39, dentro de `#if DEBUG ... #endif`:
   ```csharp
   #if DEBUG
   if (!(limit is not null)) throw new InvalidOperationException("assertion failed: limit.is_some()");
   #endif
   ```
   Motivo: `debug_assert!` só existe em build de depuração no Rust (os testes rodam em debug). `Debug.Assert` encerraria o processo de teste no .NET moderno em vez de lançar uma exceção. Primeiro uso: `Ast/Query/LimitClause.cs`.

2. **`format_args!(...)` usado como valor `Display`** (`Values`: `Indent(format_args!("{prefix}({})", display_comma_separated(row))).fmt(f)`). Tradução: classe privada aninhada `FormatArgs : IDisplay` que embrulha um `Action<Formatter>`; o corpo usa `f.Write($"...")`. Uso: `new Indent<FormatArgs>(new FormatArgs(args => args.Write($"{prefix}({DisplayCommaSeparated(row.Content)})"))).Fmt(f)`. Como `core::fmt::Arguments`, cada lacuna sai com flags novos (sem `#`) no destino recebido, e as quebras de linha passam pelo `Indent`. Se aparecer em outras unidades, vale promover a classe para `Support/` (não criei, por estar fora da unidade). Primeiro uso: `Ast/Query/Values.cs`.

3. **Funções e tipos aninhados dentro de `fn fmt`** (`Join`: `fn prefix(..) -> &'static str`, `fn suffix(..) -> impl Display` e `struct Suffix<'a>(&'a JoinConstraint)` com `impl Display`). Tradução: funções locais `static` com o nome mecânico (`Prefix`, `Suffix`) e o struct como classe privada aninhada no record, com o **mesmo** nome (`private sealed class Suffix : IDisplay`, campo `.0` → `Value`). A função local e a classe com o mesmo nome compilam (`new Suffix(..)` resolve o tipo, `Suffix(..)` a função). `impl Display` vira retorno `IDisplay`. Primeiro uso: `Ast/Query/Join.cs`.

4. **`format!("({query})")` dentro de um `Display`** (`PipeOperator::fmt_set_operation` monta um `Vec<String>` antes de escrever). Tradução: `"(" + Formatter.Format(query) + ")"` (= `format!("{}", x)`, sem o flag `#`, como no Rust), e depois `DisplayCommaSeparated(lista)`. É exceção legítima à proibição de `ToString()`/`Format` dentro de `Display` do caso 30: o próprio Rust converte para `String` ali. Primeiro uso: `Ast/Query/PipeOperator.cs`.

5. **Decisão do integrador (A2) aplicada: CS8866**, campo de variante-struct com o nome de outra variante do mesmo enum. Ocorrências em A7: `TableFactor.Pivot.Table`, `TableFactor.Unpivot.Table`, `TableFactor.MatchRecognize.Table` (o enum tem a variante `TableFactor::Table`). Cada um declara `public new TableFactor Table { get; init; } = Table;` no corpo do record. **CS8859** (`clone` → `CloneValue`): nenhuma ocorrência em `query.rs`. Nenhum `using static` de enum foi usado (só `using static SqlParser.Core.Ast.AstModule;`).

6. **`f.write_str(match self { .. })`** (`SetOperator`, `TableIndexHintType`, `TableIndexType`, `TableIndexHintForClause`) e **`let x = match self { .. }; write!(f, "{x}")`** (`LockType`, `NonBlock`) → expressão `switch` (`this switch { Union => "UNION", .., _ => throw .. }`), que mantém o `match` num lugar só. Primeiro uso: `Ast/Query/SetOperator.cs`.
